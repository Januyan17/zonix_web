# Zonix Admin

Web admin console for the Zonix platform: shops, billing and free trials,
the mobile app's update gate, device logins, and history requests.

## Running

```sh
flutter pub get
flutter run -d chrome
```

A `.env` file at the project root supplies the Supabase settings read by
`lib/core/config/supabase_options.dart`.

## Project structure

```
lib/
  main.dart               Bootstrap (Firebase, Supabase, dotenv)
  firebase_options.dart   Generated by FlutterFire
  app/                    Root MaterialApp
  core/                   Shared across features
    config/  theme/  utils/  services/  widgets/
  features/               One folder per area of the product
    auth/  shell/  shops/  billing/  overview/
    app_version/  device_logins/  history_requests/
```

Each feature keeps its own `models/`, `services/`, `utils/`, `screens/`
and `widgets/`. Anything used by more than one feature and free of feature
logic lives in `core/`.
